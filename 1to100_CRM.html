Connect Your Google Sheet

This CRM syncs live with your Master List tab. Follow the 3-minute setup below to get your Apps Script URL, then paste it here.

⚙️ One-Time Setup (≈ 3 minutes)

  1. Open script.google.com → click New Project
  2. Delete all existing code and paste the contents of AppScript_Backend.gs
  3. Click Deploy → New Deployment
  4. Set Type: Web App · Execute as: Me · Access: Anyone
  5. Click Deploy, authorize when prompted, then copy the Web App URL
  6. Paste that URL in the field below and click Connect
Looks like: https://script.google.com/macros/s/AKfy.../exec
